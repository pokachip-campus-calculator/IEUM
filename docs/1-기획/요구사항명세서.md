# 요구사항 명세서

> 개발해야 할 모든 기능/비기능을 리스트업하고 우선순위를 정하는 "개발 계약서"

## 우선순위 기준
- **P1 (Must)**: 없으면 서비스 오픈 불가 (핵심 기능)
- **P2 (Should)**: 있으면 좋음 (보조 기능)
- **P3 (Could)**: 시간 남으면 함 (고도화)

## 1. 기능 요구사항 (Functional) - 시스템이 "무엇을" 해야 하는가
ID 규칙: `FR-USR-001` (업무구분 약어 + 번호)

| ID | 업무구분 | 요구사항 명 | 상세 설명 | 우선순위 | 의존성 |
|---|---|---|---|---|---|
| FR-USR-001 | 회원 | 회원 가입 | | P1 | - |
