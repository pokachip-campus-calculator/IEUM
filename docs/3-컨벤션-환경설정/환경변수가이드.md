# 환경 변수 가이드

> API Key 유출 방지, 팀원 간 실행 환경 통일. 실제 값은 절대 커밋하지 말고 `.env`는 `.gitignore`에 등록합니다.

## Key 리스트
| 변수명 | 사용처 | 로컬 개발 기본값 | 설명 |
|---|---|---|---|
| DB_URL | DB 연결 | jdbc:mysql://localhost:3306/ieum | |
| DB_USER | DB 연결 | | |
| DB_PASSWORD | DB 연결 | (팀 공유 채널에서 확인) | |

## 설정 방법
1. `.env.example`을 복사해 `.env` 생성
2. 위 표의 값 입력
