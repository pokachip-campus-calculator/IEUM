# Git 전략

> 브랜치 관리, 커밋 메시지, PR 규칙. FE/BE 각자 다르게 구성해도 됩니다.

## 1. 브랜치 전략
| 브랜치 | 용도 |
|---|---|
| main | 배포용 |
| develop | 통합 개발 |
| feature/기능-이름 | 기능 개발 |

## 2. 커밋 메시지 규칙
`타입: 한글 설명`

| 타입 | 언제 | 예시 |
|---|---|---|
| feat | 기능 추가 | feat: 대여 등록 기능 추가 |
| fix | 버그 수정 | fix: 반납일 null 오류 수정 |
| docs | 문서 수정 | docs: README 실행 방법 추가 |
| refactor | 동작 변화 없는 코드 정리 | refactor: BookDAO 중복 코드 정리 |
| sql | SQL 파일 변경 | sql: rental 테이블 FK 추가 |
